# 014 爱心铺满屏幕悬浮层

大大小小的爱心铺满整个屏幕，伴随缓慢漂浮、脉动、旋转与闪光。

- 数量：约 110 颗爱心 + 80 颗闪光
- 尺寸：60 ~ 180 像素，巨大且显眼
- 颜色：粉红 / 桃红 / 玫红 / 樱花粉 等多种暖色
- 动效：心跳脉动 + 缓慢漂浮 + 旋转 + 呼吸透明度 + 外发光

## 运行

```bash
uv run projects/014_hearts_flood_overlay/main.py
```

## 操作

- `Esc` / `Q` 退出
- `Space` 重新随机
- `F` 切换全屏
- `T` 切换鼠标穿透
- `R` 开始/停止录制
- `S` 截图
