# 014 爱心动画故事悬浮层

一段循环播放的爱心故事，依次上演 8 个阶段：

1. **飞出来** — 90 颗小爱心从屏幕四周飞入并铺满全屏
2. **铺满** — 自由漂浮、闪烁、脉动
3. **汇聚** — 所有爱心按爱心曲线排列，逐步聚拢
4. **大爱心** — 聚成一颗完整的巨大爱心，整体心跳
5. **爆炸** — 中心闪光，彩色小爱心向四周炸开
6. **泡泡** — 冒出 55 颗粉色透明泡泡，缓缓上浮
7. **祝福语** — 泡泡化作 26 句爱的祝福（我爱你、永远在一起、520、LOVE…）
8. **淡出** — 文字淡出后自动回到阶段 1 循环

- 颜色：粉红 / 桃红 / 玫红 / 樱花粉 等多种暖色
- 动效：飞入缓动 + 漂浮脉动 + 汇聚曲线 + 爆炸闪光 + 泡泡高光 + 文字淡入淡出

## 运行

```bash
uv run projects/014_hearts_flood_overlay/main.py
```

## 操作

- `Esc` / `Q` 退出
- `Space` 重新开始整段故事
- `F` 切换全屏
- `T` 切换鼠标穿透
- `R` 开始/停止录制
- `S` 截图
